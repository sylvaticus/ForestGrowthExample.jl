# ForestGrowthExample.jl

A minimal package to teach how to move from a script to a Julia package.
It fits a logistic growth model of forest stand volumes against their age, using the French National Forest Inventory data.

```julia
pkg> add https://github.com/sylvaticus/ForestGrowthExample.jl
```

```@docs
ForestGrowthExample
```
