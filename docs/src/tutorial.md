## Loading the data
By default the data of the French National Forest Inventory is downloaded from the urls used in the course
(local files can be given instead, e.g. `load_data(tree_data = "data/arbres_foret_2012.csv", ...)`):

````@example tutorial
data = load_data()
first(data, 5)
````

## Fitting the growth model for all species

````@example tutorial
pars = estimate_plot_growth(data)
````

## Fitting the growth model for the 5 main species

````@example tutorial
speciesCount = sort(combine(groupby(data, :spLabel), nrow => :count), :count, rev = true)
mainSpecies  = speciesCount.spLabel[1:5]
````

````@example tutorial
volume(age, p) = p.max_growth / (1 + exp(-p.growth_rate * (age - p.mid_age)))
plot(age -> volume(age, pars), 0, 150, label = "ALL SPECIES", linewidth = 3, legend = :topleft,
     xlabel = "age (years)", ylabel = "volume (m³/ha)")
for sp in mainSpecies
    plot!(age -> volume(age, estimate_plot_growth(data, sp)), 0, 150, label = sp)
end
current()
````
