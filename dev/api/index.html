ForestGrowthExample.estimate_plot_growth — Function
estimate_plot_growth(
    data::DataFrames.AbstractDataFrame
) -> @NamedTuple{max_growth::Float64, growth_rate::Float64, mid_age::Float64}
estimate_plot_growth(
    data::DataFrames.AbstractDataFrame,
    specie::AbstractString
) -> @NamedTuple{max_growth::Float64, growth_rate::Float64, mid_age::Float64}

Fit a logistic growth model of the volumes per hectare against the age of the inventory points in data (as returned by load_data) and return the tuple (max_growth, growth_rate, mid_age).

The fit is done on the points of the given specie label (e.g. "HETRE"), or on all points if specie is empty.

Example

julia> using ForestGrowthExample

julia> data = load_data();

julia> pars =estimate_plot_growth(data, "HETRE");

julia> map(x -> round(x, digits = 2), pars)
(max_growth = 315.12, growth_rate = 0.07, mid_age = 42.6)

ForestGrowthExample.load_data — Method
load_data(
;
    tree_data,
    dead_tree_data,
    point_data,
    doc_data
) -> Any

Load the French National Forest Inventory data and return a DataFrame of the inventory points with their timber volume per hectare (vHa), number of trees (ntrees), age class (cac, in years), main species code (esspre) and label (spLabel).

Each argument can be either a url or a local file path, and defaults to the data used in the course.

Example

julia> using ForestGrowthExample

julia> data = load_data();

julia> size(data)
(5390, 6)

julia> names(data)
6-element Vector{String}:
 "idp"
 "esspre"
 "cac"
 "vHa"
 "ntrees"
 "spLabel"

ForestGrowthExample.vHaContribution — Method
vHaContribution(v::Real, c13::Real) -> Any

Return the contribution in terms of m³/ha of the tree.

The French inventory system is based on a concentric sample method: small trees are sampled on a small area (6 metres radius), intermediate trees on a concentric area of 9 metres and only large trees (with a circonference larger than 117.5 cm) are sampled on a concentric area of 15 metres of radius. This function normalise the contribution of each tree to m³/ha.
